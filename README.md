# PNEC University Information Chatbot

## Introduction
The PNEC University Information Chatbot is a student project developed to help students find information about Pakistan Navy Engineering College (PNEC). It will provide answers to common questions related to departments, academic programmes, admissions, contacts and student facilities.

The project uses Python, Artificial Intelligence and Data Structures and Algorithms (DSA) to build a simple and useful chatbot.

## Problem Statement
Students sometimes face difficulty finding university information because it is available across different pages and documents. This chatbot aims to make finding common information easier through a single platform.

## Main Features
- Answer common questions about PNEC.
- Search information from a stored dataset.
- Identify the category of a user's question.
- Display relevant answers.
- Handle questions that are not available in the dataset.

## Technologies Used

## AI and DSA Concepts
**Artificial Intelligence:**
- Naive Bayes Classification
- Question Category Prediction

**Data Structures and Algorithms:**
- Lists and Arrays
- Dictionaries
- Searching

## Dataset
The project uses a CSV file containing questions, answers, categories and source links related to PNEC.
